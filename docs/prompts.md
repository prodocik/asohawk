# Prompt library

The maintained, copyable prompt library lives on the public [ASOHawk FAQ](https://asohawk.cc/docs/faq#prompt-library). It is the canonical version because each card has a Copy button and is updated with the product's available tools and safety rules.

It is organized into five practical groups:

- **Set up and orient**: workspace audit, adding an app, choosing integrations, tracking plans and agent guardrails.
- **Collect and validate data**: coverage checks, rank refreshes, locale research, weekly reports and budget-confirmed ASA demand measurement.
- **Improve the listing and discover growth**: keyword opportunities, metadata audit, localization, competitor research, reviews and screenshots.
- **Answer a specific question**: changes since a date, visibility movement, revenue, retention, cannibalization and public-app estimates.
- **Plan and execute safely**: approval review, task plans, release readiness and stakeholder email drafts.

Every prompt asks the agent to show evidence and limitations. Prompts do not override API-key scopes, workspace permissions, approval gates or integration prerequisites. The paid ASA prompt always follows `estimate → user budget → final confirmation`, with a $5 per-run maximum.
